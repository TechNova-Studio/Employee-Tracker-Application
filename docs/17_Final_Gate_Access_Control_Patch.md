# 17 Final Gate Access Control Patch

## Purpose
This patch fixes only final blocker access-control issues. It does not redesign BOLD WorkPulse and does not add Docker, Redis, Celery, Kubernetes, microservices or complex DevOps.

## Corrected access rules

### CompanyPlan
- Super Admin can create, update and delete plans.
- Company Admin, HR/Admin and Sales/Admin may read active plans only.
- Manager and Employee cannot manage or read plan master through the plan endpoint.

### Company
- Super Admin can create, update and delete companies.
- Company Admin can view and update only their own company.
- Company Admin can update only basic company settings: company name, legal name, contact person, email, mobile, screenshot interval, screenshot retention and idle threshold.
- Company Admin cannot create another company manually.
- Trial company creation remains only through the public demo/trial signup flow.

### Dashboard summary
- Super Admin sees all companies, users, sessions and alerts.
- Company Admin and HR/Admin see own company only.
- Sales/Admin sees only own assigned/generated trial-sales dashboard.
- Manager sees only assigned team summary.
- Employee sees only own summary.

### PolicyAcceptance
- Super Admin sees all policy acceptance records.
- Company Admin and HR/Admin see own-company policy acceptance records.
- Manager sees assigned team policy acceptance records only.
- Employee sees only their own policy acceptance records.
- Policy acceptance records cannot be created/edited/deleted through the viewset. Accept/decline must use the dedicated policy APIs.

### ERPEvent
- Super Admin sees all ERP events.
- Company Admin and HR/Admin see own-company ERP events.
- Manager can read own-company ERP events for operational review only.
- Employee cannot access ERP event payloads.
- ERP ingestion remains through `/api/erp/ingest/` using connector token authentication.

### Trial management
- Sales/Admin can manage only trial codes generated by them or assigned to them as sales owner.
- Sales/Admin cannot extend, convert or cancel a random trial company by guessing company ID.
- Company Admin can manage own-company generated/owned trial codes.
- Super Admin can manage all trial companies.
- Non-Super Admin cannot convert a trial company to Internal / Not Billable.

### AgentVersion
- Super Admin can manage global and company-specific agent versions.
- Company Admin can manage only own-company agent versions.
- Company Admin can read global versions but cannot edit or delete global versions.

## QA evidence to collect
For each test, IT should capture:
- user login email,
- API endpoint or screen,
- expected result,
- actual result,
- screenshot of success/failure.

## Do not change without management approval
- Do not allow Company Admin to create companies manually.
- Do not allow Sales/Admin to extend/convert/cancel trial companies outside assigned/generated scope.
- Do not expose ERP event payloads to employees.
- Do not allow employees to see company-wide users, sessions, alerts, audit logs, policy logs, invoices or ERP payloads.
